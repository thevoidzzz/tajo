# CONTEXT — Quién usa el patio

Estado: Aprobada
Fecha: 2026-11-11

## Encargado del patio

Registra un equipo cuando llega al tajo, anota las horas del horómetro y, cuando corresponde, deja constancia de un mantenimiento. Mira el patio para ver cuáles requieren mantenimiento.

No administra usuarios. No factura. No programa repuestos.

## Lo que esta versión hace

- Dar de alta un equipo con código, tipo y horómetro.
- Listar el patio. Quien requiere mantenimiento aparece primero.
- Corregir el código, el tipo o el horómetro.
- Quitar un equipo del patio.
- Registrar un mantenimiento y ver su historial.

Los tipos de esta versión son camión, excavadora y perforadora.

## Lo que queda fuera

Identidad, papeles, repuestos, órdenes de trabajo y un tablero de costos. El horómetro no se importa de un dispositivo: lo escribe el encargado.
